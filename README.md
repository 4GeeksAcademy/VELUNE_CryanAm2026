# VELUNE_CryanAm2026

Prototipo visual para la futura tienda online de VELUNE, una marca de moda francesa. El proyecto define la experiencia inicial de la tienda con una Home elegante, semántica, responsive y coherente con la identidad visual de la marca.

## Objetivo

Crear una base clara para el desarrollo de una tienda online con contenido indexable, estructura SEO-friendly y componentes reutilizables entre vistas.

## Alcance actual

La especificación actual se centra exclusivamente en la vista Home e incluye:

- Header reutilizable con logotipo, buscador y menú de Cuenta, Catálogo y Carrito.
- Hero para campañas o productos especiales.
- Sección de Nuevos lanzamientos.
- Sección de Más vendidos.
- Footer reutilizable con categorías, enlaces legales y contacto.
- Adaptación responsive para móvil, tablet y escritorio.
- HTML semántico, Schema.org y CSS con Tailwind.
- Sin JavaScript en el prototipo.

## Identidad visual

La propuesta sigue una dirección editorial, sobria y sofisticada, inspirada en los conceptos de sensualidad contenida, movimiento, tacto y misterio de VELUNE.

| Elemento | Color |
| --- | --- |
| Header - fondo | `#D7C8BC` |
| Header - texto | `#8F243C` |
| Body - fondo | `#F1E9E2` |
| Títulos | `#8F243C` |
| Párrafos | `#171315` |

Se evita una estética prediseñada basada únicamente en blanco y negro. El contraste se utiliza de forma elegante para reforzar la identidad de la marca.
